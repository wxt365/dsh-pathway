## 0.5.0 统一范围与资源稳定性

- 四页签上方共享回复选择及当前回复/快照范围；默认回复范围，时间线/来源/结论、搜索、统计及结构导出跟随。图始终是所选单回复关系图，快照范围下明确说明。内容导出仍需确认且只导出选中回复/结论。旧无回复记录降级快照范围，不伪造正文。
- replyScope对显式历史来源、执行祖先取闭包，按回复cut屏蔽未来结果、摘录、来源及完成序号；来源检查真实owner，避免其他节点sourceIds误引泄漏。所有来源仍是记录归属或显式引用，不自动推断证据。
- canonical compact:true nodeViews只存截面状态及引用，不重复非空input/output/error；详情必须使用getReplyNodeView。schemaVersion不变，旧canonical full视图仍严格校验兼容。90KiB返回+20KB输入+100回复回归，转换后263475字节。
- list结果按原始UTF8预算选择可容纳的候选，超大可选项整闭包回滚继续尝试更早项；必需引用闭包仍整体失败而非偷偷遗漏。响应omittedResultCount/eligibleResultCount明确结果省略。
- 单次登记复用投影；导出ID采用预留安全ID的无碰撞局部映射，避免哈希及字面opaque ID冲突。
- 集中验证：83项单元/接口、2项Cordis、4项Chrome通过。跨页签回复/快照切换、来源owner/父级闭包、未来结果屏蔽、旧记录降级、导出碰撞及列表预算均有回归。
- 本版涉及Host/core/native工具，安装后必须完整退出重开应用方能全量生效，不自动重启用户进程。仍非后端分页，底层readSession全量读取边界不变；更早回复加载、逐批恢复未在此版实现。

## 实施偏差与后续

初版采用手动刷新历史快照，而非 session/event 实时推送，以先验证来源与证据语义、减少连接/重放竞态。列表只覆盖在线会话，按 ID 的接口仍支持冷历史。结论绑定采用显式 trace 协议，尚无自动证据登记工具、语义核验或跨子 Agent 汇总。

本 MVP 可以直接离线体验并通过插件包进入后续现场联调，不等于“所有执行与推理全量透明”。
